# PlayStyle icons

The PNGs here are **generated placeholders** (`npm run icons:placeholders`).

To use your own icons, overwrite the files with your PNGs using the exact
same filenames (kebab-case of the playstyle name):

```
finesse-shot.png   power-shot.png    chip-shot.png     power-header.png  trivela.png
incisive-pass.png  pinged-pass.png   long-ball-pass.png tiki-taka.png    whipped-pass.png
first-touch.png    flair.png         press-proven.png  rapid.png         technical.png    trickster.png
block.png          bruiser.png       intercept.png     jockey.png        slide-tackle.png anticipate.png
acrobatic.png      aerial.png        quick-step.png    relentless.png    long-throw.png
far-throw.png      footwork.png      cross-claimer.png rush-out.png      far-reach.png
```

Recommended: square PNGs (~128×128) with transparent backgrounds.
Lookups go through `ICON_IMAGES` in `src/constants/playstyleIcons.ts`.
